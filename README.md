#  MindBalance AI
A smart productivity and burnout tracking system that helps students manage tasks and monitor mental fatigue using simple AI-like logic.

##  Features
-  Task Management (Add, Complete, Delete)
- Burnout Detection (Mood + Study Hours)
-  Smart Suggestions based on user input
-  Persistent Data Storage using localStorage
-  Clean and modern dashboard UI

##  Tech Stack
- HTML
- CSS
- JavaScript
- GitHub Pages

##  How It Works
- User adds study tasks
- System tracks mood and study hours
- Rule-based logic analyzes burnout level
- Provides suggestions like:
  - Take a break
  - Maintain balance
  - Improve focus
